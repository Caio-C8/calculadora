# Visão Geral

Projeto completo de uma calculadora

# Inicialização

Baixe as dependências e execute o front-end e o back-end

- **Baixar dependências e executar a aplicação**

```bash
npm run start
```

- **Baixar dependências**

```bash
npm run setup
```

- **Executar aplicação**

```bash
npm run dev
```

Depois de ter executado a aplicação abra nos links:

- [Calculadora](http://localhost:5173).
- [Teste de API](localhost:8000/docs).

## Pré-requisitos

-Ter [Node.js](https://nodejs.org/en/download) instalado.
